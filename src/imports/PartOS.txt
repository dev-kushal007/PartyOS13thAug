Final Prompt for Emergent / Figma Make
Build a premium, responsive web application called PartyOS for booking corporate experiences such as team lunches, dinners, office parties, rooftop events, breweries, clubs, and celebrations. The experience should feel modern, elegant, and frictionless, inspired by Airbnb, Apple, Notion, and Stripe. Create an end-to-end MVP with the following flow: Homepage → Search → Results → Experience Details → Login/Signup → Booking Review → 10% Advance Payment → Booking Confirmation → Profile → Booking History. The homepage should feature a minimal hero with a prominent search widget (location, event type, team size, budget, optional date), featured venues, testimonials, FAQs, and corporate trust indicators. Search results should support filters (budget, team size, cuisine, experience type, amenities, ratings) and display venue cards with images, estimated pricing, reviews, availability, and CTAs. Experience pages should include galleries, package details, pricing, capacity, amenities, reviews, maps, cancellation policy, and a sticky booking widget. Authentication should support mobile OTP and email. Booking should present a summary, cost breakdown, cancellation policy, and allow sharing the event (excluding negotiated pricing) via WhatsApp, email, or link. Payments should collect a 10% advance, generate invoices, and send email/SMS/WhatsApp confirmations. User profiles should include booking history, linked social accounts, notification preferences, saved venues, rewards, and membership tiers. Build an admin dashboard for leads, bookings, vendors, finance, analytics, and customer management with a lead pipeline from inquiry to repeat customer. Use a luxury minimal design system with generous whitespace, premium imagery, rounded cards, subtle animations, dark typography on white backgrounds, and gold accent colors. Focus on a polished MVP while keeping the architecture extensible for future features like loyalty, AI recommendations, referrals, and corporate account management.
